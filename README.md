# HP片源观测台

[打开展示页](https://sxdes.github.io/hp-source-observatory/) · [脱敏快照](https://sxdes.github.io/hp-source-observatory/report.json)

国内HP在空闲时执行固定程序，GitHub Pages仅展示脱敏快照。有效来源每6小时复查，未核实线索由原30分钟任务小批补测，导航和公开配置按每日预算轮换；观看、近期输入和抖音打开时让行。使用HP本地缓存，GitHub读取或同步失败均不会阻断已有检测，发布独立重试，0模型API。

登记来源分为导航/文章、资源站/发布页、TVBox/配置、直播/EPG、应用/自建项目、精选参考。保留原始入口、用途和出处；导航地址、普通影视网页、API结构证据及节目级播放验证分别标注。具体统计和时间以网页及report.json为准；接口或首页可读不表示无广告、整站可播或长期稳定。明确导流域名排除，未核实地址隔离；直播项目只作参考，原直播筛选仍暂停。

Gist 167入口和新增参考267入口专项已完成；后续候选由HP持续核验。程序只解析公开数据，不运行清单中的JAR、JavaScript、Python或解析器；公共导航中的JSON卡片与公开跳转地址也只按数据处理。新播放备用仍须同片同集、分片和解码验证，页面不提供影片或媒体播放地址。

精选数据参考 [laoma528/awesome-zhuiju-free](https://github.com/laoma528/awesome-zhuiju-free)，依 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)保留出处，地址已筛选并由HP独立复查；不采信上游评分或无广告宣传作为本机认证。其他项目按事实记录公开入口与研究结论，未复制执行型配置或软件。

仅发布index.html、style.css、app.js、report.json、README.md、.nojekyll六个文件。账号、密钥、会话、观看记录、设备地址、原始日志和私人截图保留在HP或本地私有维护目录。静态页面使用原生HTML/CSS/JavaScript，没有外部字体或统计脚本。

双源对照单列每集取样完整度与下载偏慢分片数；未发现相同样本不等于底层独立。只公开计数和固定名称，不公开媒体主机、分片哈希或地址。必要的人工模型研究另存维护文档，本站固定探针继续不调用模型。
