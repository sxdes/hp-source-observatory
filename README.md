# 片源观测台

HP 在国内空闲时运行固定 Python 程序。本仓库只接收脱敏静态快照；GitHub 暂时不可达不会中断检测，上传失败会独立重试。没有模型 API 调用。

- 18 个原始入口、优质发布页与Gist，共20个登记入口，导航/文章/资源网站分别保存来源编号。网页读取失败继续保留登记。
- 资源站按品牌归并；公开列表须有实际资源 API、本站内容或发布页证据。仅在旧导航出现的域名隔离待查，明确非资源站的域名禁止重新采集加入。发布页和当前资源站分别保留，优先显示资源站。普通资源站可能混有不适合家庭的类别，发现地址不自动导入片库。
- 每 6 小时最多轮换 6 个品牌检查；导航每 24 小时最多轮换 8 个入口、4 个详情页，限请求数、时间、字节。播放或近期输入时让行。
- 播放抽样单列：精确节目身份、集序、两个完整分片、两集开头解码，不把首页或 API 成功当作整站稳定。
- 非凡按用户要求停用。没有公开影片、媒体直链、账号、Cookie、密钥、设备地址、主机名或观看记录。
- 零外部字体、脚本和统计服务。源码仅用原生 HTML/CSS/JavaScript。

页面：[片源观测台](https://sxdes.github.io/hp-source-observatory/)。结果：[report.json](report.json)。

数据结构参考了 [mylazily/ziyuanzhan](https://github.com/mylazily/ziyuanzhan) 的公开资源站目录，保留来源登记；上游历史在线/测速结果不作为 HP 实测结论。页面与检测程序独立实现。

新增Gist两份配置只提取公开地址：167入口已由HP逐项检查，4个资源API通过、148失败、15未核实；不运行配置中的脚本、JAR或解析器。公开9个有资源证据的来源，208品牌线索隔离；这不是9个全片库可播认证。
